Deckhand

HTML presentations with a progress rail, a presenter window, and instructions an AI can follow.

Demo deckTheme: well-logRail: well

Deckhand is a small engine for HTML presentations. Each deck is one HTML file that works offline, with a presenter window and a progress rail.

The chart on the right is the logtrack component, drawing sample data from one attribute.

What you get

Each deck is one HTML file,
with no build step.

  1. Fixed 1920×1080 stage that scales to any screen.
  2. Presenter window with notes and a timer, synced both ways.
  3. Reveals and state changes step by step.
  4. Themes and rails you can swap per deck.

Everything is plain HTML, CSS and JavaScript. Open the file in a browser and present. Nothing to install for the audience or the presenter.

Authoring

Slides are sections with
a few attributes.

Attributes that matter

data-pos places the slide on the rail. data-label names it in the rail and run sheet. data-time sets the target seconds. data-step reveals, data-when toggles a state.

A deck is a main element with sections. The engine adds the stage, rail, overlays and presenter view around them.

These are the attributes you use most.

Press P

The presenter window
keeps you on time.

  1. Notes, with a marker for each reveal
  2. Timer, pace and target per slide
  3. Next slide and a clickable run sheet
  4. Blank screen while you switch to a demo

Press P to open the presenter window on your own screen. It stays in sync with the audience window, and either one can drive.
